# Keeping two planning conversations apart

A president can now keep a workshop checklist in one chat and debate
preparation in another. The conversation list contains titles, and
opening a title fetches its transcript. Renaming changes one row and
keeps the messages. Deleting removes only the selected conversation
and its turns.

Campusly already has the active organization roles, so the assistant
offers those workspaces when the president manages more than one. The
browser clears the previous transcript when the workspace changes.
Core stores the owner and organization on every conversation and
checks both even if the browser sends a valid ID.

During the browser check a prompt lost its last characters when Send
followed typing immediately. Uni's H5 textarea throttles updates to
its model binding. The submit event now reads the current field value.
The browser check asserts the exact submitted text before and after
switching back to the conversation.

A4 reuses the database and Go contracts from A3. The added routes make
the conversation management explicit, while inference still receives
only the bounded context for the open chat. See the
[A4 evidence](../evidence/A4.md).
