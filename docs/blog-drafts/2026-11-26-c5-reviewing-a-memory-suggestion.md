# Reviewing a preference before it becomes memory

A message about today's workshop can look like a standing
preference. Saving it automatically would make a short-lived
decision appear in later replies. The president now chooses which
saved message to check. Core offers a review when the whole message
matches a supported lasting style choice.

The review shows the candidate and asks whether to save it for
future replies in the selected workspace. Dismissal closes the
preview without writing a row. Acceptance checks the same source
again and stores only the style choice and the source link.

That link matters when the chat is deleted. PostgreSQL removes
the dependent preference with its source turn. A manually saved
choice survives because its owner made it independently of the
conversation. We keep this behavior even after a source-linked
value is edited.

An exact phrase list limits what the local prototype recognizes.
It also makes it possible to test that temporary additions and
sensitive text produce no suggestion. Broader language coverage
needs its own evaluation.
