# Drafting a notice from the recorded venue

A venue notice should name the room students can actually use. The
assistant asks Core for the first future scheduled session on the
activity. It can draft a notice when the venue is present. If the record
has no room, the assistant points the president back to that record.

The draft uses the current venue and leaves the message open for
editing. It makes no claim about a previous venue because the activity
record used here has no earlier location. The [B6 evidence](../evidence/B6.md)
shows the edit and the missing-venue check.
