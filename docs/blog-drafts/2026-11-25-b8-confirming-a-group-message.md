# Sending a reviewed group message from the assistant

A president can ask the assistant to send a message while planning an
activity. The request opens an editor for the named discussion. The
review shows the text and where it will go, and confirmation posts
it as the president through the usual discussion service.

A notice and an ordinary message have different effects in the same
room. The ordinary message creates a message event. The notice also
creates an announcement event. Both return a receipt that opens the
exact post. The [B8 checks](../evidence/B8.md) cover wrong targets,
expiry, revoked access and replay.
