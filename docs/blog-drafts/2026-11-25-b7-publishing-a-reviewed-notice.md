# Publishing a reviewed notice into the existing discussion

An activity notice belongs in the same discussion students already use.
The review shows the activity, audience, sender and full message. Core
binds the approval to the room ID and rechecks the president's authority
and membership before using the ordinary discussion send path.

The same transaction records the notice, its events and the assistant
receipt. Replaying the confirmation links back to the original notice.
The first browser run posted correctly but could not open the room
because the fixture and server signed its link with different temporary
keys. Sharing the key fixed the lab. See the [B7 evidence](../evidence/B7.md).
