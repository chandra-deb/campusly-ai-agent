# Counting registrations from current activity records

When a president asks how many people registered, a withdrawn
registration should not count. A promoted waitlist entry should not
count toward the current queue. Core uses the same predicates as the
activity service and reads both totals in one statement. The assistant
gets the numbers and links to the source activity.

Team activities need two units. The result distinguishes people with
active registrations from confirmed and waiting teams. The current
queue and capacity are visible without bringing anyone's registration
details into the chat. See the [B3 evidence](../evidence/B3.md).
