# A1 local evidence

A1 starts from AI `dcf1752`, Core `8ebce64` and H5 `81f0786`. Each repo has a
local `feature/personal-assistant-a1` branch. The owner approved A1–A4
implementation and progression after each engineering check. Personal UI
acceptance and teach-back are pending the owner's review.

## Reproduce

- In AI `service/`, use Go 1.25 and run `gofmt -l cmd internal`,
  `go test -race ./internal/personal`, `go vet ./cmd/... ./internal/personal`
  and `go build -buildvcs=false -o /tmp/campusly-assistant-bin/ ./cmd/...`.
  `-buildvcs=false` avoids Go reading linked worktree metadata in a restricted shell.
- In Core, run `python -m pytest -q tests/test_personal_assistant`.
- In H5, run `npm run type-check` and `CI=1 npm run build:h5`. The variable
  skips Uni's external update check in the local compiler.
- In Core, with Node, Chrome, Docker's local PostgreSQL 15 image, the two Go
  binaries, and H5 dependencies available, run
  `CAMS_ENV_FILE=/dev/null CAMS_PUPPETEER_MODULE=/absolute/path/to/puppeteer-core.js python -m scripts.m2.assistant_lab /tmp/campusly-assistant-bin /absolute/path/to/h5 /tmp/a1-chat.png`.
  The lab starts the assistant, Core, H5 and a temporary database on loopback,
  invokes the standalone fixture, creates synthetic roles, and tears down the
  services and database.

Owner scenario. Sign in as the synthetic president, open **Ask Campusly**
from the dashboard, send “Give me a workshop checklist” and look for the
fourth item in the complete reply. A non-president opening the same route
should see an unavailable state and no composer.

## Results

Core passed three focused tests with Python 3.14.3 and PostgreSQL 15. They
covered current president, forged actor, wrong organization, non-president and
default-off behavior. H5 type checking passed using Node 24.14.1. The first
H5 build stopped because Uni tried to enumerate interfaces for its update check
inside the sandbox. The rerun with `CI=1` skipped that check and built H5. The Go race tests and vet
passed with Go 1.25.0. The linked-worktree VCS stamp failed under sandbox
restrictions. Building both binaries with `-buildvcs=false` passed, and the
fixture returned the complete checklist over loopback.

Implementation commits before browser verification: AI `14074a2`, Core
`7bde65f`, H5 `43b5128`.

Roll back by using the parent of each A1 branch and stopping the local
assistant. A1 adds no storage or migration. This slice does not provide evidence
about real model output, provider cost, or production transport. Cloud coursework
is outside this local correctness check.

The final browser smoke passed on H5 `b8a233c` and captured the
[synthetic mobile transcript](a1-chat.png). Signing in with an explicit
return path avoided the existing dashboard redirect on an unauthenticated
cold entry. A first visual pass found that the assistant's style block
did not compile the shared Sass tokens and that the input still showed
the sent text. Both were fixed and the final run checked that the input
cleared and the non-president saw no composer.
