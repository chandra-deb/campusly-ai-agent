# B1 local organization answers

B1 lets a president ask which organizations they manage while working
in a private chat. The scoped Go intent response carries neither names
nor memberships. Core checks current authority and returns at most 20
matching organizations directly to H5. Switching chats drops the result.

## Owner scenario

Open **Manage** → **Ask Campusly** as the synthetic president and
create a chat. Ask “Which organizations do I manage?” Check that
Workshop Society and Debate Society appear, with the current workspace
marked. Reopen the chat and ask again. The owner accept-or-fix decision
is pending. The recognizer supports the sample wording and a few
variants. Hosted language understanding and Cloud performance are
unmeasured.
