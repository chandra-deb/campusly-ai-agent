# A4 local conversation management evidence

A4 adds private conversation listing, create and rename to the existing
open and hard-delete capabilities. H5 switches by conversation ID and
clears the transcript on organization changes. Core keeps up to 20
conversations per president and organization, with up to 100 complete
turns in each. It accepts titles of 1–80 characters. The A3 migration
and Go contract carry forward. The tested implementation is Core
`ddbb254` and H5 `5f31928`.

## Reproduction

1. Follow [the local lab setup](../../README.md#review-phase-a-locally)
   using the three matching A4 branches. Use `--review` to keep the
   synthetic accounts and disposable database open for manual checks.
2. In Core, run `python -m pytest -q tests/test_personal_assistant`.
   Nine focused tests passed against PostgreSQL 15. The new cases
   exercised separate conversations, preserved turns on rename, scoped
   listing, denial of another president's rename and delete, and the cap.
3. In H5, run `node --test src/modules/president/composables/use-president-org.test.mjs`,
   `npm run type-check` and `CI=1 npm run build:h5`. These checks passed
   with Node 24.14.1. The browser scenario uses the same automated lab
   command as [A1](A1.md#reproduce) with the A4 worktrees and A3 Go binaries.
4. The Go v1 fixture and v2 context service use the binaries tested in
   [A3](A3.md). The local runtime retains the deterministic adapter.

## Browser result

The final browser run created two named chats with separate turns, switched
between them, verified the second organization had an empty list, then
deleted one chat and checked that the other's exact prompt and reply
remained. The review launcher also returned a working loopback H5 entry
and exited cleanly on Ctrl+C. See the [synthetic mobile screenshot](a4-conversations.png).

The first combined run timed out at Core startup. Running the checks
separately with a longer lab startup allowance got the stack ready.
The harness then selected the organization explicitly and waited for
each modal and request to settle. It also uncovered prompt truncation
when Send followed typing immediately. A4 reads the form's current
textarea value and the final check asserts the exact text after send
and after reopening the surviving conversation.
