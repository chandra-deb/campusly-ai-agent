| Gate | Dependency | Exit |
| --- | --- | --- |
| Foundation | Owner's repository decision | Public repository, product reference and reviewable design options |
| A — Design review | Foundation | Owner resolves AI01 and authorizes one implementation task |
| B1 — Standalone contract demo | A | AI10 passes from a clean checkout with synthetic data |

Foundation is documentation only. A awaits review. B1–B4 and extensions are PENDING. Core tracks infrastructure scale-out after B4 and separate authorization. The Cloud course deadline remains independent of prototype acceptance and optional scaling; audit existing evidence and protect a defensible submission. ML studies have separate protocols and approval.

The initial prototype may run on one host with independently runnable service/worker boundaries. Production rollout is not implied by local acceptance. Each task/milestone maintains living report and blog drafts as described in the Definition of Done. The task queue is a recommended MVP order with explicit technical prerequisites, not a universal dependency chain; later independent increments can be planned separately after the prototype.
