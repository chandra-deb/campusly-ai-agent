# Learning from implementation

For each decision keep one example the owner can reproduce, the alternative considered and what failed. Review the actual receipt, source or retry trace together before recording a lesson. Track owner understanding separately from passing tests.

For a later ML study, freeze model/version, tool contracts, held-out synthetic cases and scoring rules before comparing grounding, abstention, useful replies, action integrity, privacy, latency and cost. Preserve failures and limitations. Core owns infrastructure experiments and the Cloud report. A research claim needs evidence beyond a successful demo.
